# 爾雅明朝

## 概述
「**爾雅明朝**」是一款 16×16 點陣明朝體，主要由考哈設計並繪製。現仍處於開發階段。

## 設計理念
爭做一款人人**免費使用**、**符合字理**、同时**最美觀**的**傳承字形**點陣字體！
