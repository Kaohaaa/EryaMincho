# 爾雅明朝

![image](./images/preview.png) 

## 概述
「**爾雅明朝**」是一款 15×15 點陣明朝體，主要由考哈設計並繪製。現仍處於開發階段。

## 設計理念
爭做**人人可用**、**符合字理**、同时**最美觀**的**傳承字形**點陣字體！

## 覆蓋
計劃支持 CJK 統一漢字基本區和擴展 A 區。
